# Early Warning Signals of the Onset of an AMOC Collapse

Optimal Observation Locations for Early Warning of the Onset of an AMOC Collapse (March 2025)

E.J.V. Smolders, René M. van Westen and Henk A. Dijkstra

These directories contain Python (v3) and Matlab (2022b) scripts for plotting/analysing model output.

Python and Matlab scripts can be found in the directory 'Program'. Model output can be found in the directory 'Data'.

The processed model output are stored as NETCDF files and using the relevant scripts one can regenerate the figures. Some scripts (e.g., FOV_index_34S.py and AMOC_transport.py) use the original model output (not given here), but the generated time series are already available in the relevant directories. Furthermore, the file containing the restoring rate time series used for the changepoint analysis (Tipping_time_estimation.py) is too large and we only provide the changepoint times in .mat file.
